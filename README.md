# C++ Programming Practice 🚀

Welcome to my personal archive for C++ programming. This repository tracks my journey in mastering the C++ language, core object-oriented principles, and standard library implementations using **Code::Blocks**.

## 📌 Repository Structure
- `Basics/` - Control structures, loops, functions, and pointers.
- `OOPs/` - Classes, objects, inheritance, polymorphism, encapsulation, and abstraction.
- `STL/` - Vectors, pairs, maps, sets, and algorithm headers.
- `Data_Structures/` - Manual implementation of basic stacks, queues, and linked lists.

## 🛠️ Environment & Tools
- **Language:** C++17 / C++20
- **IDE:** Code::Blocks
- **Compiler:** GCC / MinGW
